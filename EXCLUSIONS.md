# Publication exclusions

The original project is untouched. This fresh repository imports selected files, with no private Git history. All original final reports, proposals, signatures, student identifiers, report exports and the frozen release directory are excluded. No report was regenerated or edited.

Also excluded: internal conversations, decision/findings logs, task instructions and handoffs, execution logs and receipts, obsolete drafts, downloaded papers and publisher pages, virtual environments, caches, unrelated files, credentials and authentication material. Operational helper source may refer to historical private manifests; those references are code, not included private records.

Raw Cboe/Yahoo/Nikkei or other vendor histories, normalized per-event response arrays, forecast/feature rows that reveal source observations, fitted-model archives containing underlying observations, licensed extracts and bulk replication archives are not distributed. Public access does not establish redistribution permission. Reacquire inputs under the relevant provider terms; see DATA_ACCESS.md. Included results are analytical summaries, model parameters, test statistics, simulation recognition counts and original aggregate research plots, not source-price histories. No downloaded publication figure is included.

SOURCE_MAP.json is an explicit allowlist of copied files. Additional repository files are publication documentation and lightweight verification tools. Historical review documents informed the README but are not published as internal agent discussions. Superseded intermediate results are omitted where a final version is available. Code retains historical names/import layouts, and selected continuation code is retained for methodological traceability.

No repository-wide open-source licence was selected because the user did not specify one. Inclusion does not transfer ownership of third-party material or imply permission to redistribute external data. The repository starts private.
