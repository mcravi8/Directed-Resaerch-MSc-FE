## Input and lineage

Use only the 19 VIX30D events eligible for the complete 120-session, free-asymptote S02a cohort, reconstructed by `pipeline.inputs()` and `pipeline.panels(ts, ev, 'VIX30D', 120, 'argmax')` in `stages/S02a_pooled/scripts/pipeline.py`, with `protocol_core.normalize`. Inputs are `omori_pipeline/data/vix_term_structure.csv`, `omori_pipeline/data/shock_events.csv`, and `stages/S02a_pooled/pooled_summary.json`. The latter supplies the historical empirical start-1 E2 and start-5 E1 parameter vectors. Preserve the legacy Lehman/GFC merge, peak anchors, next-onset exclusion, 250 valid pre-onset closes, and original event ordering by event ID. At E2 start, snapshot and hash raw inputs and code before parsing; fail a mismatch or non-19 reconstruction. Do not read those outcome files during E1.

Define z_i(t) for t=0..120 using log closes, pre-onset log mean, and peak log denominator in `protocol_core.normalize`; z_i(0)=1. Let y(20) be the cohort mean at t=20, b the historical start-5 E1 free baseline, and w,t_fast,t_slow the historical start-1 E2 mixture. Curves have amplitude 1-b: E1=b+(1-b)exp(-t/27.8); E2=b+(1-b)[w exp(-t/t_fast)+(1-w)exp(-t/t_slow)]; PL=b+(1-b)(1+t/c)^(-0.7); SE=b+(1-b)exp[-(t/s)^0.6]. Set r=(y(20)-b)/(1-b), require 0<r<1, c=20/(r^(-1/0.7)-1), s=20/[-log(r)]^(1/0.6). Do not recalibrate these to synthetic outcomes. Residual R_i(t)=z_i(t)-E2_historical(t), then subtract the across-event mean at each t. Save calibration parameters and cohort/date mapping at E2 start.

## Noise and synthetic units

Cross four truths {E1,E2,PL,SE}, N {19,40,80,160,320}, two designs {independent,calendar_joint}, 200 replication IDs 0..199. Generate one synthetic panel per truth/N/design/replication and fit starts {1,5} to that same panel: 4×5×2×200=8,000 panels and 16,000 scored cases. Each cell's 200 are separate seeded Monte Carlo units, not bootstrap estimates of one panel. Use `protocol_core.seed('Extension','E2',truth,N,design,rep,subkey...)`, base SEED=5902026 and PCG64 `numpy.default_rng`; record NumPy/SciPy/Python versions and source/code hashes. Fit-start seeds have a distinct `fit` subkey and do not regenerate the panel. Retain immutable unit IDs; atomically save complete units, failures, scores and seeds. No S02c simulation outcomes enter the new replications.

Independent design: for every synthetic event, independently sample one of 19 residual rows with replacement. Concatenate circular blocks of 10 positions, each block start uniform on 0..120 of that row, until 121 positions; truncate. Set e_i(t)=draw_i(t)-draw_i(0), and path=truth(t)+e_i(t). This reproduces C1's event-independent mechanism.

Calendar-joint design: derive each event's observed calendar-session anchor index from the same VIX30D date index; its 121 t positions map to anchor index+t. Connect events if their [anchor,anchor+120] calendar-index intervals intersect, taking transitive components. A component is a source template with its event IDs, anchor offsets from its first covered index, 121-position masks, and all shared calendar coordinates. Derive one residual value per covered calendar coordinate: first calculate R_i(t) above, then average R_i(t) across all cohort events mapping to that coordinate. This calendar residual bank is sampled in consecutive observed-session runs of covered coordinates. To draw a synthetic component, sample circular length-10 blocks from a uniformly chosen eligible run and uniformly chosen block start within that run; repeat until the selected template's full calendar span is filled, truncating the final block. Use one drawn value for each template calendar coordinate, and reuse that exact value for every event covering that coordinate. Each event receives e_i(t)=draw(anchor_offset_i+t)-draw(anchor_offset_i), so its synthetic z_i(0)=1. Gaps in a template's covered calendar span remain masked; draw coordinates across the span once, but never create separate values for a shared coordinate. All blocks, run choices and template draws use the replication's seeded generator. The template's original observed-session offsets are preserved; do not force calendar-day gaps to be equal session gaps. This is a dependent noise mechanism; N is event count, not independent-cluster count.

Draw source components uniformly with replacement until adding the next component would reach or exceed N. If it equals N, keep all events. If it exceeds N, uniformly sample without replacement exactly the needed event IDs within that one component, sort by source event ID for serialization, and retain their original relative offsets and common drawn calendar field. This boundary truncation can remove events but never resamples surviving events' shared coordinates independently. Record source component, selected IDs, offsets, masks, sampled residual calendar-run/block starts, synthetic event count N, and source-component draw ID, distinct source-component count, and synthetic component-draw count. Repeated draws of the same source component are distinct synthetic draws but one distinct source cluster. A component with all selected events shares its complete field. Require a deterministic synthetic test with overlapping windows to show identical shared-coordinate draws and a distinct independent-design test; fail the construction if either fails. If raw metadata cannot reproduce the declared mapping, stop E2 without substituting independent events.

Boundary-truncation audit: use the same deterministic replication RNG subkey `boundary_audit` and save, for every overshoot, truth/N/design/rep, source component ID, ordered candidate IDs, m candidate count, k needed count, selected IDs, excluded IDs, draw ID, and inclusion probability k/m for every candidate. From the 200 planned replication IDs per cell, report selected/candidate frequency by source event ID together with the varying k/m probabilities; these empirical frequencies are diagnostics, not a substitute for the exact conditional probability. Check each selected set has exactly k unique IDs, all IDs come from the candidate component, and selected events retain the original offsets/masks and identical shared-coordinate noise where they overlap. Save a seeded overlapping-window fixture that forces boundary selection and checks both retained shared draws and exclusion. Report event N, synthetic component-draw count and distinct source-component count per truth/N/design/rep and their distributions by cell. An incomplete audit or coupling mismatch makes the calendar-joint cell unestimable; never silently replace it.

## Fits, classification, estimands

For each start s=1 or 5, pool N paths by arithmetic mean at each t=s..120 and fit all four families with the exact free-asymptote `protocol_core.BOUNDS`, `curve`, `ordered`, `fit` (32 bounded TRF starts, ftol=xtol=gtol=1e-8, max_nfev=5000) and `score`: AIC=n log(SSE/n)+2k, n=121-s, k=3/5/4/4 for E1/E2/PL/SE. SSE=0 has score -infinity per inherited code. A fit succeeds only if a finite converged start exists. Preserve each start record, best parameters, active bounds and point score. If any family has no valid fit, classify `unclassified_fit_failure`; do not choose among survivors. Otherwise choose minimum score; exact ties use order E1,E2,PL,SE, and record all tied families. No margin or bootstrap-win gate.

For every truth×N×design×start cell, report 200-denominator counts for winner E1/E2/PL/SE and unclassified; correct recognition count/rate and two-sided Wilson 95% interval with z=1.959963984540054. Also show success-conditional recognition descriptively with its denominator. Incomplete planned units are `pending`, not failures or a completed 200-denominator scientific rate. Primary recognition display is calendar-joint/start 5; the design-level conjunctive N80 uses both starts. All other recognition cells are secondary descriptive. No formal cross-cell significance test.

For each truth×N×design×start, separately report PL-truth miss rate = (200 minus PL-truth PL-winner count)/200, plus false-PL rates = E1-, E2-, and SE-truth PL-winner counts/200, with counts, rates and two-sided marginal Wilson 95% intervals. Unclassified fit failures count as PL misses when PL is true and as non-PL classifications for each false-PL numerator; report unclassified counts beside every rate so this convention is visible. These four named error estimands and PL recognition use the planned denominator 200. A planned unit that is missing/corrupt is pending, never a scored miss or non-PL; no scientific rate or N80 is final until all relevant cells have 200 completed classified-or-fit-failure units.

For each design define one conjunctive N80: the smallest tested N at which, simultaneously at both starts s=1 and s=5, PL-truth PL-winner count/200 >=0.80 and each of the E1-, E2-, and SE-truth PL-winner counts/200 <=0.10. There are eight required component rates at each N: two PL recognition rates and six false-PL rates. List all eight counts/rates and marginal Wilson intervals for every design×N, plus separately the PL miss rates. A single unmet component disqualifies that N. If any required cell is incomplete, N80 for that design is pending unless a fully observed qualifying N exists and every smaller tested N is also fully observed; do not infer a threshold through missing cells. If no tested N qualifies after all cells complete, report `not attained on tested grid through 320`. No interpolation, smoothing, extrapolation or confidence-qualified threshold claim. Show design×start thresholds using the same four components at a single start only as secondary diagnostics; the two-start conjunction is the estimand. Calendar-joint design is primary; independent design is secondary. No formal cross-cell significance test.


## Execution and audit

No tuning based on new outcomes. Checkpoint each paired-start replication atomically with unit ID, spec/input/code hash, seed, elapsed time, status and error. On continuation verify hashes, reconcile workers, reuse valid units, rerun only missing/corrupt units with original seeds, and preserve failed units. Each authorized execution run has an eight-hour elapsed ceiling, with atomic checkpoints and hash-verified resume of incomplete units; continuation of already authorized work does not require a new stage trigger.
