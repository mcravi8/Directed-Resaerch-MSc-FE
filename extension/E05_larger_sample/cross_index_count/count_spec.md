# Cross-index event counting freeze

This is a review-informed additive count, not a new model fit or a blinded preregistration. Sources are fixed local SHA-256 snapshots of VXN, RVX, OVX, GVZ, VXEEM, VXAPL, VXAZN and Nikkei 225 VI. The latter four are newly included histories; other named sources lack an established usable full history or terms. No raw histories are exported to the connected folder.

Apply the earlier E4 causal onset rule separately to each index: one-session level rise >=35% or five-session rise >=50%, each measured against its own prior observed sessions; accept at most one onset in any 30-calendar-day span. Require 250 strictly prior valid sessions, strictly positive arithmetic baseline, full onset..+10 peak window, and full anchor..+119 response window, with anchor the maximum close over onset..+10 (earliest tie). Exclude an event if the next accepted onset falls on/before its response end. Do not impute. Record all accepted onsets and exclusions.

For eligible rows, merge exact equal calendar onset dates across indices in a date catalog. Then form transitive connected components of inclusive intervals [250th prior observed session, anchor+119th observed session] across *all* indices. These are full data-use-footprint dependence units, distinct from unique onset dates and from the prior E4 onset..+119 components. Count components by membership and index. A component is a conservative resampling unit, not proof of stochastic independence. No inferential claim when fewer than ten components. Calendar differences, index methodology, coverage, source terms, and the prior E5 execution chronology continue to limit interpretation.

Outputs: source manifest, accepted-event catalog, date-merged catalog, full-footprint component ledger, summary, number ledger. Deterministic code, no RNG. Freeze this specification and executable code hash before examining computed new outcomes. Prior known E4: 35 potential windows, 28 dates, 13 short-window components; prior E5: 84 trajectories, seven global full-footprint components.
