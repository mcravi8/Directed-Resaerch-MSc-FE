## Frozen-design candidate, to hash in S01 before new analyses
Use inherited 33-event merged catalog, all four maturities with actual observed dates. Historic diagnostic reproduction keeps its original definitions; new analysis is separately versioned.
Primary horizon 120 sessions after anchor, complete balanced cohort with 250 strictly pre-onset observations and positive normalization denominator >1e-8. Sensitivity 61 and 250 sessions, complete cohorts separately declared; next-onset truncation causes exclusion from a full-horizon cohort, never imputation. Report common-event maturity comparisons separately from full per-maturity cohorts; no winner-based exclusions.
Normalize z(t)=(log V_m(anchor+t)-mu_m)/(log V_m(anchor)-mu_m), mu_m=mean of 250 pre-onset log closes. Equal event weights, no flooring undershoots. Raw-level scale and prior 20-session level normalization are historical, not the new pooled primary. Retain t as time from anchor, do NOT reset t to zero at each fit start.
Four free-asymptote families: E1=b+a exp(-t/tau); E2=b+a[w exp(-t/tau1)+(1-w)exp(-t/tau2)]; PL=b+a(1+t/c)^(-p); SE=b+a exp(-(t/tau)^beta). Stretched exponential chosen instead of Mittag-Leffler for numerically stable evaluation, beta in [0.1,1], with beta=1 the exponential boundary. Common b in [-2,2], a in [0,5]; w in [0,1], ordered tau1<=tau2; time constants [0.2,5000] sessions, c [0.001,100000], p [0.01,1000]. Fixed b=0 is sensitivity. Starts t={1,3,5}, t=1 primary comparison, all three reported without selecting a winner by start.
32 seeded parameter starts per model, seed 5902026 keyed by stage/model/maturity/start/replicate; bounded TRF least squares tolerances 1e-8, max_nfev 5000. Finite converged fits only; all failures/boundary hits recorded, never hidden. Parameter-count score n log(SSE/n)+2k descriptive only; correlated time points and boundary nesting prevent conventional AIC-based significance claims.
Event bootstrap: 499 resamples of entire event trajectories, equal event weights, refit all four models at every start. Paired maturity comparison resamples common event IDs together. Also group-block resample overlap-connected events as dependence sensitivity; inference with <10 groups is descriptive. Report sample/event/group counts, percentile intervals and bootstrap win fractions as stability, not probability of truth. No post-hoc significance thresholds. Save every replicate.
Selection rule for simulation recovery, frozen before draws: family winner only if its point AIC beats every other family by >=2 and it wins in >=90% of the 199 event-bootstrap refits used per simulation panel; otherwise undetermined. If E2 collapses (w<0.05 or >0.95 or tau2/tau1<2), PL or SE yields EXP-like curves (maximum separation from fitted E1 <0.05 pooled residual SD), classify as undetermined, not evidence for a distinct family. All numerical failures/insufficient events count as undetermined in unconditional recovery denominator; report conditional eligible rate separately.
