# S02c C1/C2 frozen analysis specification

Source: Matteo's 23 October comments C1-C2, Lyra's editorial source, decision log D-55. This specification precedes any S02c simulation outcomes. Approval artifact 60D2B0DB-6686-43BC-BF8E-6EAEEDE8EEAA was referenced in the assignment but is not present among accessible project files; this provenance gap is reported separately.

## Common fit and cohort

Use the 19 VIX30D events eligible in the complete 120-session, free-baseline S02a cohort. Reconstruct the exact event IDs, dates, peak anchors, no-next-onset truncation, 250-session pre-onset log baseline and normalization from `stages/S02a_pooled/scripts/pipeline.py` and `protocol_core.py`. Preserve all event positions and window lengths. Fit the mean normalized path at t=1 and t=5 with E1, E2, PL, SE; use the frozen S01 32-start bounded TRF routine and AIC score, with its bounds and 199 event-resampling draws. Seed each stochastic draw by SHA256 via `protocol_core.seed`, base seed 5902026, with namespaced keys beginning `S02c`. A tie is resolved in family order E1, E2, PL, SE. Record optimizer failures, never impute a winner. All four truth arms use 200 independent replications. Checkpoint after each replication and stop before eight hours of wall time in any invocation. Never rerun the OU pilot.

## C1 injection recovery

Construct truth curves on t=0..120 with z(0)=1. Set baseline b to the empirical 30D E1 start-5 fit baseline, and amplitude 1-b. E1 tau is 27.8 sessions. E2 shape uses the empirical 30D start-1 E2 fast/slow constants and mixing weight, with amplitude adjusted to z(0)=1. SE beta=0.6, with scale chosen so z(20) matches the empirical mean normalized path. PL p=0.7, with c chosen so z(20) matches that same value. This ensures a visibly curved PL within the observed horizon. The reference residual bank consists of each empirical normalized event trajectory minus the empirical pooled E2 start-1 fitted curve, centered across events at each t. For each synthetic event, draw circular moving blocks of length 10 from an independently selected residual event, concatenate to 121 points, add to truth and normalize to synthetic z(0)=1 by subtracting its t=0 residual. This retains the actual cohort's event count and date structure; report this residual recentering explicitly.

Per truth, fit the point pooled path and 199 event-bootstrap pooled paths at both starts. Report truth x start x point-winner counts, Wilson 95% intervals, distribution quantiles of the point winner's bootstrap win fraction, comparison with empirical 0.65 (start 1) and 0.82 (start 5), and E1 fitted tau bias under E1 truth. Report any failed fits.

## C2 peak selection

Use the same E1 truth, extending from onset through 129 sessions. Estimate AR(1) coefficient and innovation standard deviation by pooled lag regression of the C1 empirical event residual bank; record them. For 200 independent simulations, create an AR(1) noise path starting from its stationary distribution, add to E1 truth, choose the argmax of sessions 0..9 as the selected peak, and align the following 121 observations to that peak. Normalize each aligned path by its observed value at the selected peak, using the same baseline b; fit E1 and E2 at start 1 with the frozen fit routine and AIC. Record E2-win fraction with Wilson 95% interval, selected-peak offsets, and E2 fast tau quantiles (both all E2 fits and E2 winners). A selected peak near the end still has a full 121-point window because the simulated path extends to session 129. This is a peak-selection mechanism check, not an estimate of a real-world causal process.
