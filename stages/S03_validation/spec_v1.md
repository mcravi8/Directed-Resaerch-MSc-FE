# S03 validation execution specification v1

Authorized stage: S03 only, after S01 and D-51 S02a empirical PASS. This is a review-informed design with earlier diagnostics already known. Execute `python3 stages/S03_validation/scripts/run.py` from project root. Seed 5902026. Input and code exact-byte hashes are in `freeze_manifest.json`; outcomes must be generated after this freeze.

Use the inherited 33-event catalog with Lehman and GFC Peak merged, actual observed dates and maturities VIX9D, VIX30D, VIX3M, VIX6M. No selected-family filter. For each event/maturity and design, truncate at next onset and require 250 valid strictly pre-onset observations, positive log normalization denominator >1e-8 and complete anchor through test dates. Peak anchor primary: train t=5..24, test 25..44; sensitivity: 1..20 and 21..40. Onset+5 anchor repeats both splits. Test is never used to choose anchor for the onset+5 check. Normalize by pre-onset mean log level and anchor difference; inverse-transform using those frozen values.

Fit E1, E2, PL and SE independently to each current training segment, using inherited free asymptote and shape bounds, 32 deterministic TRF starts, 1e-8 tolerances, maximum 5000 evaluations. Save fit failures and boundary contacts. No S02a pooled fitted parameters enter forecasts. Compare unselected families on identical test dates. RW, intercept AR1 and intercept HAR(1,5,22) use the last 756 observed pre-onset closes, require at least 252 regression rows, and recurse from training-end state without test updating. Benchmark coefficients never use onset or later observations. If 756 observations are unavailable, benchmark is excluded explicitly, while valid curve forecasts remain. Save predictions before scoring. Event loss is mean test log squared error and mean raw absolute error; aggregate with equal event weights, taking square root of mean event log MSE for log RMSE. Paired complete-event comparison against RW; 9999 overlap-group bootstrap draws when at least ten groups, otherwise descriptive. Bootstrap uses frozen SHA-keyed seed from S01 core.

Predictor: exactly 20 observed VIX30D sessions strictly before onset; OLS slope of log closes against 0..19. B20 is their raw mean; shock size is log(peak/B20). Target is mean over 20 sessions after frozen peak of (V_t-B20)/(V_peak-B20), with positive denominator and no clipping. A subsequent onset within those 20 target sessions excludes the event. Feature and target dates define overlap-connected LOGO groups. Require >=20 complete events, >=10 groups and >=15 training events per fold, or report non-estimability. Same cases and folds for size-only and size-plus-build-up; ridge penalty 1 with train-only standardization and unpenalized intercept. Paired MAE, per-group errors and 9999 group-bootstrap draws use seed 5902026. Historical VRP, SKEW and VVIX are appendix-only; no predictor tuning.

Bootstrap of S02a curves, fixed-zero baseline fits, simulation recovery, OU pilot, likelihood ratio tests, and S02b are not applicable to this held-out stage. Independent perturbation and arithmetic verification, counts, exclusions, and readback are required for acceptance.
